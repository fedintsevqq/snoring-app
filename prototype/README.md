# Прототип детектора храпа (этап 0)

Задача этапа: за одну-две ночи на MacBook понять, хватает ли готовой модели YAMNet, чтобы находить храп. Записи и результаты остаются на вашем компьютере, в git они не попадают.

Как это работает: `record` пишет ночь в Opus, `detect` прогоняет её через YAMNet и склеивает храп в эпизоды, `review` готовит слепую выборку 30-секундных окон. Вы слушаете их и отмечаете, где храп. По разметке считаются точность и полнота.

## Подготовка на Mac (один раз)

Сначала проверьте процессор:

```bash
uname -m
```

Нужно `arm64` (Apple Silicon, M1 и новее). Для Intel-Mac (`x86_64`) у `ai-edge-litert` нет сборки, и `pip install` упадёт. Если у вас Intel, скажите, подберём другой рантайм.

```bash
brew install ffmpeg
ffmpeg -hide_banner -encoders | grep libopus     # должна быть строка с libopus
cd prototype
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
python -m hrapometr_proto.fetch_model            # скачает YAMNet, 4 МБ
python -m pytest -q                              # все тесты должны пройти
```

Нужен Python 3.11 или новее.

## Проверка микрофона

```bash
python -m hrapometr_proto.record --list-devices  # найдите номер встроенного микрофона
python -m hrapometr_proto.record --out runs/test --device 0
```

При старте скрипт сам слушает микрофон 3 секунды и печатает уровень. Если микрофон отдаёт тишину (нет доступа или не то устройство), запись не начнётся. При первом запуске macOS спросит доступ к микрофону для Терминала: разрешите (Системные настройки, Конфиденциальность, Микрофон).

Минуту поговорите, потом Ctrl+C. Проверьте, что запись слышно, и пропустите её через детектор:

```bash
python -m hrapometr_proto.detect runs/test
```

## Ночь

1. Поставьте Mac на зарядку. **Крышку не закрывайте**: с закрытой крышкой и без внешнего монитора Mac уснёт, и запись оборвётся. Яркость экрана уберите в ноль.
2. Не подключайте и не включайте наушники и другие аудиоустройства: номер микрофона может смениться. Скрипт печатает имя выбранного микрофона, проверьте его при старте.
3. Поставьте ноутбук в пару метров от кровати, лучше на уровне матраса.
4. Запустите и ложитесь спать:

   ```bash
   python -m hrapometr_proto.record --out runs/night-1 --device 0
   ```

5. Утром Ctrl+C. Скрипт покажет длительность и размер ночи (нам нужны мегабайты в час: в ТЗ оценка 30–60 МБ за ночь).

Если ffmpeg упадёт или зависнет, скрипт перезапустит запись (до 10 раз) и выведет строку с `!!!`. Ошибки лежат в `runs/night-1/ffmpeg.log`. Перерывы видны в `session.json`, а `detect` предупредит, если звука меньше, чем времени на часах.

## Разбор

```bash
python -m hrapometr_proto.detect runs/night-1
python -m hrapometr_proto.review prepare runs/night-1
```

`detect` напечатает сводку: сколько эпизодов, какой процент ночи с храпом. `prepare` напечатает путь к `runs/night-1/review/index.html`. Откройте страницу в Safari или Chrome. Там 80 окон по 30 секунд (по 40 из помеченных детектором и из непомеченных, вы не знаете, из какой группы окно). На каждое уходит 20–30 секунд, всего около 40 минут. Хотите быстрее: `--per-group 25`.

Отметьте каждое окно и нажмите «Скачать labels.json». Потом:

```bash
python -m hrapometr_proto.review report runs/night-1 ~/Downloads/labels.json
```

Отчёт попадёт в `runs/night-1/review/report.md`. Его цифры и ваши заметки («что слышали, чего не хватает») перенесите в `docs/proto-results.md`.

Если после разметки снова запустить `prepare`, выборка сменится, и старый `labels.json` не подойдёт: `report` скажет об этом. Разметьте заново по новой странице.

## Если результат плохой

Не нужно размечать заново. Те же размеченные окна показывают, что было бы при другом пороге:

```bash
python -m hrapometr_proto.review sweep runs/night-1 ~/Downloads/labels.json
```

Таблица печатает точность и полноту для порогов от 0.1 до 0.8. Выберите порог и пересчитайте эпизоды без повторного прогона модели:

```bash
python -m hrapometr_proto.detect runs/night-1 --reuse --threshold 0.5
```

Ещё два рычага:

- Храп пропускается, потому что запись тихая: `--gain-db 12` усилит звук перед моделью. Это требует нового прогона модели (без `--reuse`).
- Много ложных срабатываний на дыхании: поднимите порог или склейте реже, `--max-gap 3`.

## Проверка на тестовых клипах (без Mac и без ночи)

```bash
python -m hrapometr_proto.smoke fetch    # ~110 клипов ESC-50 (CC BY-NC), около 50 МБ
python -m hrapometr_proto.smoke eval
```

Показывает, что модель вообще узнаёт храп: на 40 клипах храпа она находит 39. Это чистые короткие клипы, на реальной ночи цифры будут хуже.

## Приватность

Папка `runs/` содержит записи вашей спальни, время сна и разговоры. Она в `.gitignore`, не добавляйте её в git и не отправляйте никуда. То же про `data/` и `models/`.
