# Прототип детектора храпа (этап 0)

Задача этапа: за одну-две ночи на MacBook понять, хватает ли готовой модели YAMNet, чтобы находить храп. Записи и результаты остаются на вашем компьютере, в git они не попадают.

Как это работает: `record` пишет ночь в Opus, `detect` прогоняет её через YAMNet и склеивает храп в эпизоды, `review` готовит слепую выборку 30-секундных окон. Вы слушаете их и отмечаете, где храп. По разметке считаются точность и полнота.

## Подготовка на Mac (один раз)

```bash
brew install ffmpeg
ffmpeg -hide_banner -encoders | grep libopus     # должна быть строка с libopus
cd prototype
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
python -m hrapometr_proto.fetch_model            # скачает YAMNet, 4 МБ
python -m pytest -q                              # 43 теста должны пройти
```

Нужен Python 3.11 или новее.

## Проверка микрофона

```bash
python -m hrapometr_proto.record --list-devices  # найдите номер встроенного микрофона
python -m hrapometr_proto.record --out runs/test --device 0
```

Минуту поговорите, потом Ctrl+C. При первом запуске macOS спросит доступ к микрофону для Терминала: разрешите (Системные настройки, Конфиденциальность, Микрофон). Затем проверьте, что запись слышно, и пропустите её через детектор:

```bash
python -m hrapometr_proto.detect runs/test
```

## Ночь

1. Поставьте Mac на зарядку. **Крышку не закрывайте**: с закрытой крышкой и без внешнего монитора Mac уснёт, и запись оборвётся. Яркость экрана уберите в ноль.
2. Поставьте ноутбук в пару метров от кровати, лучше на уровне матраса.
3. Запустите и ложитесь спать:

   ```bash
   python -m hrapometr_proto.record --out runs/night-1 --device 0
   ```

4. Утром Ctrl+C. Скрипт покажет длительность и размер ночи (нам нужны мегабайты в час: в ТЗ оценка 30–60 МБ за ночь).

## Разбор

```bash
python -m hrapometr_proto.detect runs/night-1
python -m hrapometr_proto.review prepare runs/night-1
```

`detect` напечатает сводку: сколько эпизодов, какой процент ночи с храпом. `prepare` откроет путь к `runs/night-1/review/index.html`. Откройте страницу в Safari или Chrome. Там 80 окон по 30 секунд (по 40 из помеченных детектором и из непомеченных, вы не знаете, из какой группы окно). На каждое уходит 20–30 секунд, всего около 40 минут. Хотите быстрее: `--per-group 25`.

Отметьте каждое окно и нажмите «Скачать labels.json». Потом:

```bash
python -m hrapometr_proto.review report runs/night-1 ~/Downloads/labels.json
```

Отчёт попадёт в `runs/night-1/review/report.md`. Его цифры и ваши заметки («что слышали, чего не хватает») перенесите в `docs/proto-results.md`.

## Если результат плохой

- Много ложных срабатываний на дыхании: поднимите порог, `--threshold 0.5`.
- Храп пропускается, потому что запись тихая: `--gain-db 12` усилит звук перед моделью.
- Менять порог и склейку можно без повторного прогона модели: добавьте `--reuse`.

## Проверка на тестовых клипах (без Mac и без ночи)

```bash
python -m hrapometr_proto.smoke fetch    # ~110 клипов ESC-50 (CC BY-NC), около 50 МБ
python -m hrapometr_proto.smoke eval
```

Показывает, что модель вообще узнаёт храп: на 40 клипах храпа она находит 39. Это чистые короткие клипы, на реальной ночи цифры будут хуже.
